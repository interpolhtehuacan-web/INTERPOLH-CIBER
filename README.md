# ESPARTANOS — Proteger y Servir

Primera propuesta web basada en el contenido entregado en el documento Word.

## Archivos
- index.html
- styles.css
- script.js
- assets/ (imágenes extraídas del Word)

## Publicación
La carpeta completa puede subirse a un hosting estático o a GitHub Pages.

## Nota
El contenido textual se mantiene basado en el documento original. Antes de publicar conviene revisar ortografía, datos de contacto y afirmaciones comerciales con el cliente.
